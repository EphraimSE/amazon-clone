# Amazon Clone

A full-stack e-commerce web application that replicates core Amazon functionalities including product browsing, shopping cart management, user authentication, and checkout

## Features

### Core Features
- **User Authentication**
- **Product Management**
- **Shopping Cart**
- **Checkout & Payments**
- **User Account Mngr**
- **Admin Panel**

## Tech Stack

### Frontend
- **React 18** - UI library
- **React Router** - Navigation
- **Axios** - HTTP client
- **Stripe.js** - Payment integration

### Backend
- **Node.js** - Runtime environment
- **Express.js** - Web framework
- **MongoDB** - NoSQL database

### DevTools
- **Nodemon** - Auto-reload during development
- **Postman** - API testing
- **Git** - Version control
